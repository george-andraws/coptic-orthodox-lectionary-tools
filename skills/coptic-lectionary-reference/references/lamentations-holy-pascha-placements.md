# Lamentations in Holy Pascha Lookup Note

Use this when a Bible-study or lectionary task asks about Lamentations in Coptic Orthodox Holy Week.

## Confirmed placements from checked sources

- **Good Friday, Twelfth Hour:** Lamentations 3:1-66, introduced as `A reading from the book of Lamentations of Jeremiah the Prophet`.
- **Hosanna Sunday, Ninth Hour:** Lamentations 1:1-4 surfaced in the same local Holy Pascha source. Treat this as a finding to preserve, but do not expand a chapter guide unless it is in scope.

## Sources checked

- Local source-text search in the Holy Pascha package: `St_Mary_Ottawa_Katameros_Holy_Pascha_EN.txt` and `St_Mary_Ottawa_Katameros_Holy_Pascha_EN_Coptic_AR.txt`.
- Tasbeha.org: `Good Friday :: 12th: Lamentations of Jeremiah :: Ⲑ̀ⲣⲓⲛⲟⲓ Ⲓⲉⲣⲉⲙⲓⲟⲩ`, https://tasbeha.org/hymn_library/view/1678.

## Lookup pattern

If `scripts/query_lectionary.py --passage "Lamentations"` returns no ordinary result, do not conclude absence. Use `--source-text "Lamentations"` and search the special-service/Holy Pascha source text directly. Holy Pascha material may be present in TXT/PDF source extracts even when ordinary passage lookup is empty.

## Reporting pattern

- Say `confirmed` for Lamentations 3:1-66 at Good Friday Twelfth Hour when using the checked sources above.
- Explain the liturgical context: the Twelfth Hour moves from the Crucifixion toward burial; the rite includes Lamentations, Paschal Praise, litanies, prostrations, procession, and burial hymn context.
- Do not generalize this into `the whole book of Lamentations is read on Good Friday`. The confirmed Good Friday reading is chapter 3:1-66.
