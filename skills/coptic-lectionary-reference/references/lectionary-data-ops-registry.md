# Lectionary Data-Ops Registry

This file preserves data-engineering, validation, package, and release references that previously lived before the main `coptic-lectionary-reference` skill body.

Do not load this for normal Bible-study lectionary lookup. Load it only when the task involves the lectionary data package, Coptic Reader fixture validation, reverse-index generation, npm/package handoff, repo commits, source scoring, generated artifacts, or external data audits.

For ordinary Bible-study and lesson support, use the main skill body plus the current local lectionary lookup references.

Key durable lessons:

- Do not assume Wednesday Day mismatches are an Eve/Day off-by-one bug. In the measured Wednesday Day pass, stored Wednesday Day matched 21/26 fixture items and stored Wednesday Eve matched 0/26.
- Distinguish live Katameros API from local Katameros SQLite. The live API returned Pascha Wednesday hour sections; the local SQLite had no Pascha/Holy Week tables.
- Treat current Pascha verifier checks as potentially pre-Coptic-Reader expectations until rewritten around locked fixtures.
- Treat composite-vs-non-composite duplicate candidates as conflicts requiring external source validation, not silent duplicates.
